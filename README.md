# BadgeQRStudio
Badge QR Studio — локальний генератор бейджиків

1. Розпакуйте ZIP та відкрийте index.html у Chrome/Edge.
2. Для роботи потрібне підключення до інтернету: бібліотеки XLSX, QRCode та jsPDF завантажуються з CDN.
3. Завантажте CSV або Excel-файл. Перший рядок — назви колонок.
4. Виберіть ID/логін, ім’я, пароль та першу колонку процесів.
5. У клітинках процесів позначайте активний процес значенням 1, так, yes, true, x або ✓. Для кожної картки відображатиметься крапка.
6. Натисніть «Створити попередній перегляд», потім «Завантажити PDF».
7. Пароль міститься у QR-коді HASŁO. Не передавайте PDF стороннім особам.

Розмір картки в PDF: 85,6 × 54 мм. Аркуш A4, до 10 карток на сторінку.
